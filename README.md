# hxwl-06 显微镜玻片观察

染色批次、试剂库存与显微镜观察预约闭环看板。

## 技术栈

React + Vite + TypeScript + CSS，数据通过 `localStorage` 持久化，刷新页面后仍保持一致。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 闭环规则

- 染色批次绑定样本、染色方案、试剂批次、染色缸与计划时段。
- 每个试剂批次记录库存、单位和有效期；开始染色时按玻片数扣减库存。
- 试剂库存不足、试剂批次已过期、或同一染色缸日期/时段被占用时，批次不能开始。
- 染色完成后玻片写入染色日期和方案有效期，只有已染色且在预约日期未过期的玻片可预约。
- 同一显微镜同一日期/时段不能重复占用；一个玻片不能存在多个未完成预约。
- 完成观察后玻片状态变为已观察，原始结论冻结。
- 复看不能覆盖旧结论，只能新增带原因的修订，修订链按顺序保留。
- 取消批次时立即释放染色缸，未完成预约同步取消，未观察玻片作废；已观察玻片和结论保留冻结。
- 批次已扣减试剂不在取消时自动回库，界面明确提示需走实验室盘点/入库流程。
- 所有批次、库存、预约、玻片状态和修订链统一写入本地存储键 `hxwl-06-closed-loop-v1`。

## 页面模块

- 染色批次看板：待开始、染色中、已染色、已取消批次和规则拦截原因。
- 可预约玻片：按染色有效期、过期状态和预约占用自动筛选。
- 观察预约：显微镜时段占用、登记观察、取消预约。
- 冻结结论：原始观察结论与复看修订链。
- 资源日历：按日期查看染色缸和显微镜占用。
- 试剂库存：批次效期、库存余量、低库存和过期标识。
