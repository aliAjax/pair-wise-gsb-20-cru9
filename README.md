# hxwl-06 显微镜玻片观察

染色批次与观察预约闭环：样本、染色方案、试剂批次、染色缸、玻片、显微镜预约与结论修订链。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 业务闭环

- **染色批次**：批次绑定样本、染色方案、试剂批次与有效期；同一染色缸同一时段只能一批；开始染色时校验试剂效期与余量（过期或不足均不能开始），通过后自动扣减库存；完成染色后玻片获得有效期并开放预约。
- **观察预约**：仅可预约「已染色且未过期」的玻片；同一显微镜同一时段不能重复占用；已观察玻片可再次预约复看。
- **取消批次**：释放染色缸时段，未观察玻片全部作废，已观察玻片冻结（结论保留），关联的待观察预约一并取消。
- **复看修订**：复看只能新增带原因的修订版本，旧结论标记为历史版本并完整保留，形成可溯源的修订链。
- **持久化**：全部状态写入 localStorage，刷新后批次、库存、预约与修订链保持一致；页头可一键重置演示数据。
